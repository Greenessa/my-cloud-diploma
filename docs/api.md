# API

## Аутентификация (/api/auth/)
| Метод |  адрес | Описание | Доступ | 
| POST | /api/auth/register/ | Регистрация пользователя | Анонимный |
| POST | /api/auth/login/ | Вход пользователя в систему | Анонимный |
| POST | /api/auth/logout/ | Выход пользователя из системы | Авторизованный |
| GET | /api/auth/me/ |	Текущий пользователь (кто залогинен) | Авторизованный |

## Users

| Метод |  адрес | Описание | Доступ |
| GET | /api/users/ | Получение списка пользователей с инфо о хранилищах | Админ |
| GET | /api/users/{id}/ | Информация о конкретном пользователе | Админ или сам пользователь |
| DELETE | /api/users/{id}/ | Удаление конкретного пользователя | Админ |
| PATCH | /api/users/{id}/ | Body: { "is_admin": true или false } Изменение признака Администратор или другого поля |

## Files 

| Метод |  адрес | Описание | Доступ |
| GET | /api/files/ | Cписок файлов пользователя из своего хранилища | Авторизованный |
| GET |	/api/files/?owner={id} | Список файлов указанного пользователя (только для админа is_admin=true) | Админ |
| GET | /api/files/{id}/ | получить JSON c данными файла (имя, дата итп) | Авторизованный (свой или админ) |
| GET | /api/files/{id}/download/ | Загрузка файла пользователя с диска | Авторизованный (свой или админ) |
| POST | /api/files/ | Загрузка файла пользователя на диск (Content-Type: multipart/form-data)| Авторизованный |
| DELETE | /api/files/{id}/ | Удаление файла | Авторизованный (свой или админ) |
| PATCH | /api/files/{id}/ | Изменение имени/комментария. Body: `{ "file_name": "новое" }` | Авторизованный |
| GET | /api/files/{id}/share/ | Получить/сгенерировать публичную ссылку на файл | Авторизованный (свой или админ) |
 
Пример ответа GET /api/files/ :
{
  "files": [
    {
      "id": 1,
      "file_name": "отчёт.pdf",
      "size": 1048576,
      "comment": "важное",
      "uploaded_at": "2026-09-28T10:15:00Z",
      "last_downloaded_at": null,
      "share_token": "3f2c1a9b-4d5e-6f7a-8b9c-0d1e2f3a4b5c",
      "share_url": "https://mycloud.example.com/api/share/3f2c1a9b-4d5e-6f7a-8b9c-0d1e2f3a4b5c/"
    }
  ]
}

## Публичный доступ (/api/share/) — без авторизации

| Метод |  адрес | Описание | Доступ |
| GET | /api/share/{token}/ | Скачать файл по публичной ссылке | Анонимный |

## Коды ответов 
401 — не авторизован
403 — нет прав
404 — не найдено
400 — ошибка валидации входных данных
